# Wiederkehrende Quellmessungen werden versioniert

Kumulative Health-Exporte erzeugen keine neuen kanonischen Samples, wenn sie dieselbe logische Quellmessung erneut enthalten. Eine stabile Quell-ID oder eine datentypspezifische natürliche Identität verbindet die Exportvorkommen; geänderte spätere Vorkommen werden als neue Quellmessungsversion bevorzugt, ohne frühere Versionen und darauf basierende Analysen zu löschen.
