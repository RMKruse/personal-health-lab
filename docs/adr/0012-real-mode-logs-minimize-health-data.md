# Logs im realen Datenmodus minimieren Gesundheitsdaten

Die Standardprotokollierung des realen Datenmodus enthält technische IDs, Status, Zähler und Fehlerklassen, aber keine Gesundheitswerte, Medikamentennamen oder personenbezogenen Dateipfade. Diese Einschränkung erschwert einzelne Diagnosen bewusst; detaillierte Diagnosedaten entstehen nur nach ausdrücklicher Benutzerfreigabe. Diagnosepakete zeigen vor dem Speichern eine Inhaltsvorschau und redigieren persönliche Felder standardmäßig.
