# Synthetische Daten verwenden den realen Importpfad

Synthetische Entwicklungsdaten werden von einem getrennten Entwicklungsmodul als versionierte Apple-Health-ähnliche XML-Exportpakete erzeugt und durchlaufen dieselbe ZIP-, Parser-, Validierungs- und Normalisierungspipeline wie reale Exporte. Der getrennte Einstiegspunkt `healthlab-dev` und Tests können den Generator verwenden; `healthlab`, das reale Anwendungsmodul und der reale Datenmodus nicht. Dadurch testet die Entwicklung keine künstliche Abkürzung; die nachgebildete Struktur wird gegen reale Exporte validiert und angepasst, weil Apple zwar XML-Export zusichert, aber kein stabiles vollständiges Exportschema garantiert. Reale Exporte und daraus abgeleitete Daten bleiben außerhalb des Repositorys; versioniert werden ausschließlich vollständig synthetische oder nachweislich anonymisierte Fixtures.
