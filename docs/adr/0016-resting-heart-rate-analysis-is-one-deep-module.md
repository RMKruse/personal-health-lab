# Die Ruhepulsanalyse ist ein tiefes Modul

Das Ruhepulsanalysemodul verbirgt Snapshot-Auflösung, Tagesmerkmale, Modellreifeprüfung, regularisierten Distributed-Lag-Fit, Moving-Block-Bootstrap, Diagnostik und Ergebnispersistenz hinter einer Analyseoperation. Statistische Teilschritte bleiben interne Seams, sodass CLI, Streamlit und End-to-End-Tests weder ihre Reihenfolge noch ihre Speicherabhängigkeiten kennen.
